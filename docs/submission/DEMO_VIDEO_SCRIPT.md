1. Use an existing sanitized capture from the completed route-level smoke only if a human review confirms that it exposes no key, identifiers, payload, raw output, terminal detail, or token usage.


## Failure contingencies

- If a Sample scene fails, reset and re-record only that local scene.
- If loading takes too long, cut from the action to the completed state; do not fake intermediate values.
- If Evidence focus is unclear, capture it again in Sample Mode.
- If no safe Live capture exists, use the evidence slate without apology or ambiguity.
- If the edited timeline exceeds 2:59, shorten transitions and cursor movement before removing required proof.
- If any sensitive surface appears, discard that take rather than blurring only a small region whose tracking could fail.
